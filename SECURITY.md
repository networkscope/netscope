# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security vulnerabilities seriously. Please report them responsibly.

**How to report:**
- Email: security@netscope.dev (preferred)
- GitHub Security Advisory: Use the "Security" tab in the repository

**What to include:**
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Your contact information

**What to expect:**
- Acknowledgment of your report within 48 hours
- Regular updates on progress
- A fix within a reasonable timeframe
- Credit in the security advisory (if desired)

## Security Best Practices

When using NetScope:

- Only scan systems you own or have explicit permission to assess
- Review scan targets carefully before running assessments
- Store assessment databases securely
- Keep NetScope updated to the latest version
- Use appropriate network segmentation for scans

## Reporting Security Issues in the Documentation

See `docs/security.md` for information about NetScope's intended use and
security considerations.

## Disclosure Policy

We follow responsible disclosure. Vulnerabilities will be fixed and a patch
released before public disclosure, unless there's a compelling reason not to.

Thank you for helping keep NetScope and its users safe.
