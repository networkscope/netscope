# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-25

### Added
- Initial release
- `scan` command for asset and service discovery
- `changes` command for comparing snapshots
- `serve` command for HTTP API server with embedded web frontend
- OpenAPI 3.0 specification (`docs/openapi.yaml`)
- JSON and CSV output formats
- SQLite persistence for assessment data
- Rule-based security findings engine
- Asset relationship graph modeling
